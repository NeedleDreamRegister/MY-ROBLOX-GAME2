## Осыпание, большие формы и сохранения

- `pyramid-v1` — неизменный шаблон для165/455/2925/562475. Нельзя менять форму под тем же идентификатором: восстановится проданный песок/испортятся сохранения. Миграции — отдельные проверяемые операции.
- VoxelField хранит занятость чанками, без Part на каждую ячейку. Сеть выбирает sparse или delta от шаблона; удалённый чанк в delta обязательно имеет явную нулевую запись. Не удалять это как «пустой мусор».
- Каждая пустота поднимается при переносе песка, budget уменьшается; старые соседние пустоты пробуждаются, заполненные отменяются. Масса и высотный потенциал проверяются, дополнительные ресурсы за осыпание не выдаются. Персонаж в целевой ячейке останавливает перенос до освобождения.
- Очередь больше не теряет4097-ю задачу: предел — исходная масса. Продолжение до8задач/50ms, до2ms расчёта между задачами; один Flush/сетевой пакет на порцию, до8косметических движений. Это пределы работы, не гарантия FPS на любом устройстве.
- Конверты1/2/3 читаются. При >4096 задач крупной формы применяется **конверт4/xyzb-v1**,5печатных символов на x/y/z/оставшийся budget; порядок очереди сохраняется. Старый читатель отвергает4 без записи. Не откатывать SaveSession/Codec отдельно от валидаторов и World.
- Terrain-адаптер резервирует заранее пустую область, отказывает чужому материалу/пересечению, пишет порциями, при ошибке/закрытии восстанавливает Air. Исходные миллионы пустых массивов больше не удерживаются; резерв состоит из метаданных. Не ослаблять проверку пустоты и не освобождать область после неудачного восстановления.
- Production store: `DigMountainPlots_v1`, ключ владельца `player_11883917519`. Legacy: `DigMountainPrototype_v1/shared_world_v1`. QA: `DigMountainMigrationQA_2026_11_12`, отдельные уникальные ключи. Записи игроков/lease/бэкапы не публиковать. Не запускать два production Play одного аккаунта одновременно.
- Полный размер562475 (примерно600×600×300) **не включён в рабочий профиль**. Четыре полных серверных региона/2249900ячеек проверены на стенде с3синтетическими владельцами, не4реальными клиентами. Нельзя выдавать это за готовый большой мультиплеер.

## Как повторять тесты и не терять время завтра

- Сначала заново найти Studio через MCP list_roblox_studios: старый id не является гарантией. Подтвердить PlaceId, Edit, attrs, текущий Source. Затем целевой тест, без повторения полного аудита.
- После изменения файлов **проверять живой Source до запуска Play**. В одном стрессе остался LocalScript до синхронизации ограничения звука; Source в Play не содержал `activeDigSounds<6`. Stop → проверка Edit Source → Play решили это. Изменённый Source во время Play не доказывает выполнение новой версии.
- MCP execute_luau сам возвращает CameraType Scriptable к Custom; это реально наблюдалось в Output. Для точного кадра использовать camera_position/look_at_position у screen_capture. При мышином тесте проецировать через текущий Camera:WorldToScreenPoint, не предполагать центр после reset камеры. На этом viewport GuiInset был58px, Mouse.UnitRay совпадал с ScreenPointToRay(Mouse.X,Mouse.Y).
- Возвращать значения из execute_luau; print не даёт результата вызова. Для большой таблицы метаданных возвращать HttpService:JSONEncode; огромная таблица Source вернулась как `[Complex Table]`.
- Require в Edit может держать старый ModuleScript. Для чистого модульного теста загрузить Source через loadstring/setfenv со script=obj, require=рекурсивныйfreshloader, __index=getfenv(0). В Server loadstring недоступен: временный ModuleScript.Source → require в новом Play. Стенды не сохранять в Edit.
- Для приватного Play использовать PersistenceEnabled=false и заметную надпись «БЕЗ СОХРАНЕНИЙ». Если главная игра отключена, клиентские WaitForChild-предупреждения ожидаемы; они не доказывают поломку обычного запуска.
- `tests/SandFeedbackFX.server.luau` — только косметический стресс, не доказательство изменения Terrain. Реальная масса/форма проверяются отдельно World/Field/Terrain.
- `tests/CartTurning.server.luau` — частный cart-only стенд, главная игра выключена; реальный Q, Corner/AssertBlocked, движение и release. Не применять его к живому production World.
- `tests/LargeCollapseQueue.spec.luau` —10000валидных пустот, encode/decode, повреждения, память/по желанию реальный QA store. `tests/LargeQueueWorld.server.luau` — настоящий World.Close/Start с временным Terrain и подставным store.
- `tests/FourExpandedPlots.server.luau(height)` —4серверных региона,3синтетических владельца; обычный SessionOnly и TerrainHeight12/74. В Read-shop есть shim для synthetic account, покупки/награды/права не подменены. Это не многоклиентский тест.
- Прежние проверки: компактное сохранение/потеря ответа/lease, native chunk profile, connected holes/World, tall74, рост455→2925 и офлайн-награды прошли. Конкретные результаты/QA ключи — PROGRESS.md. Полностью перепроверять их нужно при затрагивании соответствующих контрактов.
