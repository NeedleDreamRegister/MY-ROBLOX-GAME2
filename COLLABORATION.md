# Работа вдвоём и смена аккаунта ChatGPT

## Сохранение — это три разных действия

- Ctrl+S в Roblox Studio сохраняет изменения в файл на компьютере.
- Commit фиксирует версию в локальном Git.
- Push отправляет коммиты на GitHub, чтобы напарник получил их.

Наличие одного аккаунта Roblox не синхронизирует локальные файлы между компьютерами через GitHub. Сохранение/публикация в Roblox и отправка в GitHub — отдельные действия.

## Если меняется только аккаунт ChatGPT на том же ПК

Локально сохранённый файл остаётся на диске. Можно продолжить работу с другого аккаунта, если открыть ту же папку и актуальную карту. Перед переключением остановите текущую задачу агента и сохраните изменения в Studio.

Отправить изменения на GitHub можно в конце следующей сессии. Однако полезно делать commit перед передачей работы: это удобная точка восстановления.

У другого аккаунта нет автоматически перенесённой истории этого чата и памяти. Дайте ему HANDOFF.md и AGENTS.md, откройте ту же рабочую папку. Подключения GitHub и Studio в другом аккаунте могут потребовать повторного подключения.

Если работа велась только в облачной среде либо изменения существуют только в тексте чата/вложении, сначала нужно скачать или применить их к локальному проекту. Правило про сохранение на диске относится именно к локальным файлам.

## Удобная схема для двух разработчиков

Один общий репозиторий; каждый входит в GitHub под собственным аккаунтом. В этом репозитории у подключённого аккаунта уже есть право push.

GitHub Desktop позволяет работать без командной строки:
- В начале: Fetch origin, затем Pull origin при наличии изменений.
- В конце: сохранить Studio-файл внутри папки репозитория, Commit to main, затем Push origin.
- Не получать новую версию поверх несохранённой открытой карты в Studio. Сначала сохраните свою работу или закройте старую копию.
- Не редактируйте одну карту параллельно. Передавайте работу после успешного Push.

Если сейчас открыт файл D:/Projects/DIG-THE-MOUNTAIN_Backup3.rbxl, помните: GitHub Desktop следит только за файлами в папке клонированного репозитория. Для дальнейшей работы откройте MY-ROBLOX-GAME.rbxl из этой папки либо явно сохраните/скопируйте новую версию туда.

## Короткое сообщение следующему Codex

«Продолжай существующий проект. Сначала прочитай AGENTS.md и HANDOFF.md. Актуальная карта — MY-ROBLOX-GAME.rbxl. src/ — экспорт скриптов, автоматическая синхронизация Rojo не настроена. Не создавай игру заново. Пробел должен сразу высаживать из машинки на ходу. Перед изменениями получи актуальную версию GitHub».
