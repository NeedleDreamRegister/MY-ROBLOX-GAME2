# Начни здесь — DIG THE MOUNTAIN

Пакет для продолжения разработки с другого аккаунта Codex. Составлен 15 ноября 2026 года по связанным чатам, сохранённым отчётам и текущему состоянию Roblox Studio.

## Что делать владельцу

1. Сохрани и распакуй весь архив в постоянную папку на компьютере.
2. На другом аккаунте Codex открой эту папку как рабочий проект.
3. Дай Codex текст ниже. Для работы с картой подключи к нему Roblox Studio.
4. Основная карта пакета — **MY-ROBLOX-GAME.rbxl**. Это последняя локальная скачанная копия `D:/Projects/сад.rbxl`; более ранняя версия с транспортом лежит в `backups/`.
5. Для продолжения именно облачной игры открывай существующий проект «новая карта супчик», PlaceId **123243510098281**, UniverseId **10776747096**. Не создавай новую игру вместо него. Сохраняемый прогресс относится к существующей игре, а не к аккаунту Codex.

## Текст для нового Codex

> Продолжай существующую Roblox-игру DIG THE MOUNTAIN / «Сад карьера». Сначала полностью прочитай AGENTS.md, HANDOFF.md, TECHNICAL_MAP.md, KNOWN_ISSUES.md и CHANGELOG.md. Всё уже установлено в MY-ROBLOX-GAME.rbxl; не создавай проект заново и не запускай заново старые строительные скрипты. Сначала проверь, какая карта сейчас открыта в Studio. Береги гору, копание, автоматы, инструменты, тачку, конвейер, экономику и сохранения. Не восстанавливай истощённую гору. Лавочки и беседка убраны с карты, но сохранены в ServerStorage.QuarryGardenFurnitureArchive — без просьбы владельца не возвращай их. Дорога уже шириной 24 studs, электрокар QG Touring установлен. Пробел немедленно высаживает из него даже на ходу. src/ — экспорт 67 скриптов, автоматической синхронизации Rojo нет. Объясняй по-русски, просто и последовательно; проверяй только относящееся к текущей задаче. Не трать время на повторные проверки копания при работе с внешним видом. Последняя ошибка отсутствующей горы была вызвана выключенным доступом Studio к API сохранений; владелец уже включил его, гора из 67525 ячеек загрузилась, сохранение подтвердилось. Дальше выполняй только новое задание владельца.

## Что находится внутри

| Файл / папка | Назначение |
|---|---|
| HANDOFF.md | Общая актуальная картина игры и важные решения из разных чатов |
| TECHNICAL_MAP.md | Где находятся системы и как они связаны |
| CHANGELOG.md | История развития и отменённые решения |
| KNOWN_ISSUES.md | Исправленная ошибка загрузки, ограничения проверок |
| src/ | 67 скриптов, сверенных с текущим Studio |
| script-manifest.json | Соответствие файлов экземплярам в Explorer |
| reports/ | Исторические отчёты; старые цифры и незавершённые этапы не являются актуальным заданием |
| evidence/ | Результаты проверок и контрольные записи |
| screenshots/ | Снимки разных этапов с указанием стадии в имени |
| backups/ | Более ранние полные карты для восстановления |
| SOURCE_INDEX.md | Использованные чаты, файлы и происхождение версий |
| CHECKSUMS.json | SHA256 файлов пакета |

Текущие решения в HANDOFF.md и TECHNICAL_MAP.md важнее устаревших предложений в reports/. В этом пакете нет нового задания на разработку: следующий шаг выбирает владелец.
