## Установлено

- `.agents/skills/` содержит 128 навыков: 10 скопированы из открытых MIT-репозиториев, 118 созданы для этого проекта по списку пользователя. `roblox-networking` из списка уже входил в скопированные навыки и повторно не создавался.
- `MSayib/roblox-dev-skill`: `roblox-dev-skill` с папкой `references` и лицензией MIT. Версия `99bbcbc4f3101a0e50c9aa054f6aca319ad147db`.
- `luumenlabs/luau-skills`: `luau-core`, `luau-performance`, `luau-types`, `roblox-api`, `roblox-cloud`, `roblox-core`, `roblox-data`, `roblox-networking`, `roblox-oauth` с их `references` и лицензией MIT. Версия `6550b6b4c36390b759b4a9ee04783a343c5883e2`.
- Новые навыки перечислены в `tools/BuildRequestedSkills.py`; `node tools/BuildRequestedSkills.mjs` создаёт отсутствующие папки и не перезаписывает существующие. Для пяти навыков игры инструкции вручную уточнены по текущим путям кода.

Codex может обнаруживать навыки проекта из `.agents/skills/` при новом запуске чата в этой папке. Это локальные файлы проекта: они не загружены в аккаунт, не обязаны отображаться во вкладке ChatGPT «Плагины → Навыки» или в списке установленных плагинов. Ни один GitHub-репозиторий из этого задания не был зарегистрирован как плагин. Для появления навыка во вкладке ChatGPT его нужно отдельно загрузить или создать через интерфейс при наличии соответствующего доступа. Навыки не меняют код игры и не запускают Studio сами по себе. При использовании внешних справочников проверять актуальные Roblox API: версия движка, указанная в скачанном навыке, является снимком на дату автора.

## Проверка и границы

Структурная проверка: все 128 каталогов имеют `SKILL.md` с корректным `name` и `description`, совпадающим именем папки, без незаполненных шаблонов. Функциональное поведение каждого навыка в новом чате не проверялось. Roblox Studio для этой задачи не запускалась; игровой код и опубликованная сцена не изменялись.

## Добавление в интерфейс приложения

По просьбе пользователя создан локальный плагин `dig-the-mountain-skills` с теми же 128 навыками. Исходный пакет: `plugins/dig-the-mountain-skills/`; архив: `generated/dig-the-mountain-skills-0.1.0.zip`. Личная установленная копия: `C:\Users\devv\.codex\plugins\dig-the-mountain-skills`; каталог: `C:\Users\devv\.agents\plugins\marketplace.json` с источником «Dig the Mountain — локальные навыки» и политикой `INSTALLED_BY_DEFAULT`.

Сборка прошла: 128 навыков в пакете и архиве, 216 файлов установленной копии совпали по SHA-256 с исходным пакетом. Это регистрация **локального каталога плагинов** на данном компьютере, не публикация навыков в облачном аккаунте ChatGPT. Документация OpenAI требует перезапуска ChatGPT desktop после изменения локального marketplace. Экран после перезапуска не проверен: инструмент управления интерфейсом завершился ошибкой `windows sandbox failed: helper_unknown_error: setup refresh had errors`. После перезапуска открыть «Плагины», выбрать источник «Dig the Mountain — локальные навыки», проверить карточку «Dig the Mountain Skills» и при необходимости нажать «Установить». Появление каждого навыка отдельной карточкой во вкладке облачных персональных навыков пока не подтверждено.
