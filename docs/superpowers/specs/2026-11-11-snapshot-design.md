# Снимок маленького прототипа

Пользователь разрешил закрытую публикацию на текущем личном аккаунте и дальнейшие необходимые действия с игрой. Подтверждение повторно не требуется. Технические доступы MCP и Studio ещё выключены; облачные операции не обходить через Play.

Первый независимый шаг: подготовить формат и валидатор снимка, не подключая непроверенную запись к работающему циклу. Для нынешней общей горы рельеф и счета всех участников должны храниться в одном атомарном документе. Отдельные записи горы и денег могут восстановиться на разные моменты и повторно создать проданную массу.

Снимок v1 содержит revision, список занятых GridX/GridY/GridZ, исходные 165 ячеек, общую добычу/переносы и accounts по положительному UserId. Поддерживается только текущая пирамида 9×9×5 с ячейкой 2 studs. Перенос модели допустим, изменение размеров/ориентации требует новой версии геометрии.

Валидатор проверяет уникальность и границы ячеек, отсутствие дробей/NaN/бесконечностей, вместимость 20/40 по CapacityLevel, а также:

- remaining + dug = 165;
- сумма XP всех сохранённых счетов = dug;
- сумма переносимого песка + монет + 10 за каждое купленное улучшение = dug.

При несовместимом или повреждённом снимке загрузка должна завершиться явно: нельзя молча создать начальную гору и перезаписать сохранение. Состояние вышедшего игрока будущий слой сохранения обязан удерживать в снимке; нынешнее удаление временной записи при PlayerRemoving нужно будет изменить при интеграции.

Следующий шаг после доступа: слой UpdateAsync с блокировкой одной тестовой горы, автосохранением и release при закрытии. Личные участки и масштабирование документов — отдельное изменение. Нельзя объявлять перезапуск проверенным до реального облачного опыта.
