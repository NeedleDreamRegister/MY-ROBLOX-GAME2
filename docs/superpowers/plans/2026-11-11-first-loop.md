# Первый игровой цикл — план реализации

Пользователь утвердил `docs/interfaces/first-loop-proposal.md` и поручил Codex временные объекты A и B.

Цель: копать → заполнить 20 → продать → купить вместимость 40, без повторной добычи и продажи. Сервер хранит таблицы состояния, клиент читает атрибуты. Сохранение пока отсутствует.

- [x] Подключить учёт к SandPrototype.server.luau: заполненный запас останавливает удаление песка и XP, успешная добыча увеличивает запас и XP ровно на 1.

- [x] `src/StarterPlayer/StarterPlayerScripts/SandPrototypeHUD.client.luau`: адаптивный HUD состояния, индикатор заполнения, явная надпись без сохранений.
