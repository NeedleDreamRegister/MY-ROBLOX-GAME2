# Замер роста визуальной горы

Нужен до увеличения рабочего запаса и стоимости оборудования. Размеры 165 → 455 → 1771 Parts — тестовые варианты визуального представления, не новые горы игрока и не готовый баланс.

- [x] Проверить доступность MicroProfiler/LibMP, записать условия: Studio на этом ПК, один клиент, без DataStore, без эмуляции мощности телефона.
- [x] В Client создать отдельный локальный стенд вне игровых участков с ограниченными пакетами создания, фиксированной камерой и размерами ячеек 2 studs. Не трогать рабочие Cells или сохранения.
- [x] Снять одинаковое число кадров после прогрева; из snapshots получить медиану/p95 интервала CPU-кадра и размеры сцены. Не смешивать GPU/CPU шкалы и не объявлять это FPS телефона.
- [x] Удалить только созданный стенд, восстановить камеру/обычный режим, записать ограничения и дальнейшее решение о масштабе. Рабочие сохранения и начальные 165 ячеек не менять.
