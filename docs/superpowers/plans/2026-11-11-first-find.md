# Первая находка и музей

Следующий маленький шаг этапа 5. Тестовый предмет: один глиняный осколок PotteryShard на гору. Коллекционный, без продажи и дополнительного XP. Это проверка сохранения находок, а не окончательные шансы редкости/баланс.

**Решение:** положение скрытого осколка хранится по grid и перемещается вместе с осыпающейся ячейкой. При её настоящей добыче фиксируется finderId; для помощника — номер его накопительного outbound. В собственном профиле коллекция получает уникальный ключ источника после подтверждённого импорта соответствующего песка. Повторное подтверждение не создаёт второй предмет; находка остаётся в музее после продажи песка.

**Совместимость:** новая схема 3 через отдельный SandPrototypeFindData поверх проверенного CoopData; схемы 1/2 мигрируют без изменения массы/кошелька. Старые версии должны отказать на схеме 3, а не стирать новые поля. Перед миграцией сохранён профиль схемы 2 и отдельная сцена кооперации. Для существующих гор предмет размещается только в оставшейся ячейке, уже выкопанный песок не возвращается.
